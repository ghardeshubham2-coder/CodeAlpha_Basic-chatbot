# CodeAlpha_Basic-chatbot

A simple and interactive **rule-based chatbot** developed using Python.

This project is designed for beginners to understand how **functions, conditional statements, loops, user input, strings, and the datetime module** can be combined to create a basic conversational program.

---

## 📌 Project Overview

The Smart Basic Chatbot interacts with the user through the command line.

It recognizes predefined messages and provides appropriate responses.

The chatbot can:

- 👋 Greet the user
- 😊 Respond to different moods
- 🕐 Tell the current time
- 📅 Tell the current date
- 🤖 Tell its name
- ❓ Display available commands
- 🙏 Respond to thanks
- 👤 Personalize conversations using the user's name
- 🔢 Count the number of messages
- 🚪 Exit when the user says `bye`

---

## 🎯 Objectives

The main objectives of this project are:

1. Learn the basics of Python programming.
2. Understand how rule-based systems work.
3. Practice using `if-elif-else` statements.
4. Understand how functions are created and used.
5. Work with loops and user input.
6. Learn basic string manipulation.
7. Use Python's built-in `datetime` module.
8. Build a simple interactive console application.
